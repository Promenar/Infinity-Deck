# 功能详解

> 所属：[使用指南](README.md)。仓库首页只介绍概览，本文给出完整说明与边界。

模型管理支持独立公共目录更新（界面称“规格库”，在模型管理页右上角菜单手动更新；“同步”只指从服务商拉取模型列表）：GitHub Actions 聚合来源并签名发布，App 验签缓存并保留用户编辑。使用与维护方法见[模型目录说明](../model-catalog.md)。

## 能力一览

- **多服务商 BYOK 对话**：支持 OpenAI（Chat Completions 与 Responses）、Anthropic、Google Gemini API、Google Vertex AI、DeepSeek、GLM、Kimi 及 OpenAI-compatible 接口，包含 SSE 流式响应、多模态输入、Markdown/LaTeX/Mermaid/ECharts 渲染和会话内模型切换。表格按单元格内容计算列宽（56–280dp，超出换行），总宽超过屏幕时横向滚动，单元格内保留粗体、斜体、行内代码与链接。
- **启动自检不锁死应用**：启动恢复某一步失败时只隔离受影响的工作区、会话或子系统，其余照常使用；隔离范围只读，可在问题面板重试、确认后放弃未完成的操作、导出脱敏诊断或让 Agent 诊断。只有数据库或备份恢复本身不可信时才阻断进入，阻断页同样可导出诊断。
- **历史 Provider 安全恢复**：无法识别的历史主/额外 Provider 会在管理页显式显示且保持零联网；用户可保留名称与地址进入修复流程，明确选择新协议并处理凭证后恢复使用。
- **完整文档上下文与会话分支**：输入栏可把 TXT/Markdown 全文作为当前消息上下文发送，超出最终路由模型预算时在网络请求前阻止；会话可导出为可回传的 Markdown/TXT，也可导出为网页（HTML）、A4 分页 PDF 或长图 PNG（导出面板可选是否含思考、工具调用与附件，`/export` 可带格式参数），并可从稳定消息创建独立分支。从其他应用分享进来的文件不限格式，可导入当前或其他会话、Linux 环境任意目录或存储空间文件夹；应用不能解析的格式原样保存，Linux 会话的智能体可用 `copy_knowledge_to_linux` 把资料文件复制进 Linux 用命令处理。其他应用“打开方式”或分享的单个 Markdown 文件直接进入 Markdown 查看器，可另存为、存入存储空间或发送到会话（附件或引用，超过 1 MiB 只能引用）；大文件分块显示，超过 16 MiB 不显示正文，超过 32 MiB 不打开。
- **设置界面**：设置页共用 48dp/64dp 设置行，窄屏长标题与放大字号可自然增高；首页导航不显示脚注，详情页说明使用阅读换行。同组图标统一有或无，数值由“当前值 + 箭头”进入底部选择弹层，少量整数用行内步进器。当前条件下不生效的设置与操作保持可见但灰显，下方写明原因（例如未安装 Linux 环境时的 Linux 选项）。会话设置依次为模型、参数、工具、上下文；范围、默认值和偏好键见各设置说明。折叠屏内屏与平板（去掉导航栏后宽 ≥ 700dp、高 ≥ 480dp）设置页分两列：左列目录、右列所选设置页及其下层页面，终端、文件等整页内容仍全屏打开，开合屏保持所在页面。设置首页按模型、智能体运行（执行轮次与预算、内置工具、技能包、MCP 服务器）、知识库（知识库设置、知识图谱、长期记忆、调试与高级）、执行环境与连接、数据分组；版本号与渠道显示在“关于”行副标题，关于面板可复制版本信息、打开官网，侧载渠道可检查更新（只查询 GitHub 最新发行版，不自动安装），页尾是居中的 GitHub 标志；提供商与模型页列表行显示连接状态与能力图标，模型编辑为整页。
- **折叠屏首页三列**：折叠屏内屏与平板（去掉导航栏后宽 ≥ 700dp、高 ≥ 480dp）的「对话」页签分为功能导航、会话助手列表与会话三列，点会话在右列打开，右列没有会话时显示“新对话”入口。会话左上角的“←|”把整排左移：导航推出屏幕、列表收成带状态徽标（生成中、待批准、待回答、排队中）的图标条，会话扩为带检视器的宽会话；“|→”或系统返回还原三列，图标条顶部按钮可展开窄列表。开合屏时右列会话与整页会话互相迁移，外屏行为不变。
- **会话阅读与输入**：单行顶栏（窄窗口右侧只有选项菜单，产物、浏览器与文件是菜单首组；标题下方状态行依次是运行模式、工作区与 Git，宽度不够时先收起分支名，再把 Git 与运行模式收成图标；点工作区打开“选择工作区”面板，顶部链接进入“Agent 可达范围”）、右侧用户气泡与通栏助手正文；思考、工具、检索以自然语言步骤行呈现，默认收起、详情按需展开；运行中的命令点开工具行才显示实时输出、停止与“转入后台”，点开的行在命令结束后保持展开；流末尾的等待状态占一行常驻状态位，亲眼看着一轮结束时过程以动画收起成摘要，生成中会话流不随阶段跳动。完成回复下方提供操作行和模型时间，复制包含整轮正文；点击模型时间弹出该回复的生成统计（输入/输出 Token、缓存读取、推理 Token、首 Token 耗时、生成速度、端到端耗时与运行时间分布，多轮工具调用按整条回复合计）。思考详情支持 Markdown，审批卡顶部是类别条（内置工具或哪类命令、执行位置、风险标签），标题写“需要批准：动作”并附确切工具 ID，其下是命令或参数预览、类别说明与后台运行方式，“拒绝 / 批准”等宽并排，窄屏或大字号放不下时整组竖排、批准在上；多项审批或可限时授权时批准为分体按钮，箭头菜单含“全部批准”与“批准并免审批 10 分钟”，多项审批各带类别条列出后续调用。限时免审批按会话与类别（技能目录修改；“命令需批准”档下的命令与 Linux 系统目录修改）只存于内存，生效期间执行模式盾牌带圆点，其菜单显示剩余分钟数并可“恢复逐次审批”。子代理需要授权时，当前打开的会话在会话流底部按子代理分组显示同款审批卡（“拒绝 / 允许”），运行坞的待批准计数包含这些请求；其它会话的子代理审批仍以全局弹窗提醒。流式挂载显示已有内容，新文字按到达速率逐帧放出，生成结束后自动跟随尾部布局；生成中往回翻看会暂停跟随，推到底或滑回尾部松手即恢复；输入框、附件、执行模式、模型选择、上下文用量和发送/停止共用一个与底部导航同款厚实质感的浮岛；“+”右侧的盾牌按钮切换执行模式（命令需批准 / 免批准，免批准时换成琥珀色警示盾牌），仅在开启工具时显示。浮岛顶部是一行运行坞：显示当前步骤或运行状态、计划进度与用时，右侧依次是待批准跳转、后台任务、状态面板入口与生成中的触摸锁，与输入区之间是一排随状态流动的小灯，计划进度由文字中的“2/5”表达；点开进入运行详情（顶部状态卡写清状态、大号用时与“计划步数 · 后台任务运行中 / 已结束”；计划、后台、状态三页按页签顺序横向切换，计划按顶层分组、完成的组折叠，底部是“标记完成 / 继续处理”，后台任务按运行中 / 已结束分组，运行中带实时输出与停止），隐藏计划后状态胶囊位于浮岛上方。折叠屏内屏或平板（宽度 ≥ 600dp、高度 ≥ 480dp）时，运行信息、资源管理器、Git 变更与本会话产物收进会话右侧的浮动检视器（任务、文件、Git、产物四个页签与加宽、收起按钮都在检视器底栏，收起后是常驻右缘、贴在输入浮岛上方的带角标边缘条，也是检视器唯一的开合入口，正文让出它的宽度，输入浮岛保持全宽），浮岛不再显示运行坞；顶栏横跨全宽，检视器从顶栏下方开始；检视器打开时顶栏的图钉切换固定与浮动（全局记住，默认固定）：固定时检视器铺到底部，会话与输入浮岛让到左侧，浮动时检视器浮在会话之上、不挡输入区；加宽后会话不足 320dp 时只能浮动，图钉置灰；文件页签在仓库位置的页头是 Git 分支卡片（分支与改动数），点按切到 Git 页签；上滑面板在宽窗口改为居中对话框，模型速选、本轮记忆、运行模式与执行模式以及设置页的主题模式、语言、协议类型等短单选改为贴着触发控件弹出的浮层。生成中输入行右侧的点阵波形屏显示读数与速率柱，结束时随浮岛光效与运行坞一起收起（设置 → 外观 → 生成动效 可换成绕行流光、潮汐呼吸、网孔背光、底沿数据流或扫光点阵）；浮岛材质可选环境光（默认，光效裁剪在浮岛内部、从点阵屏一侧漫开）或毛玻璃（半透明表面实时模糊背后的会话内容）；出错时整圈泛红后消退；生成期间可以继续写下一条（含图片与文档附件），发送即进入当前会话的排队托盘，本轮成功结束后按顺序自动发出；排队消息可编辑、删除、移到最前或“插队”——当前轮在下一次工具调用结束时提前收尾、保留已完成的工具结果，随后立即发出该条。本轮失败、被停止、应用重启或结束时不在该会话，队列暂停并说明原因，点“继续”恢复。行首输入 `/` 弹出命令候选：`/技能名 补充说明` 让模型在这一轮直接按该技能工作（客户端预先加载技能说明），内置命令 `/new`、`/rename`、`/prompt`、`/compact`、`/clear`、`/mode`、`/tools`、`/export` 直达需要多步操作的会话动作，其中 `/export` 可把会话导出为 Markdown 或纯文本。助手正文长按即可自由选择文字，用户气泡的长按菜单提供“选择文本”；选字工具条中的“引用”把选中文字作为引用卡放进输入区，可逐段写批注后随消息发送（发给模型为“> 引文”加批注），用户气泡上方显示引用，点引文跳回来源那一轮；会话、消息、文件与画布卡片的长按菜单从手指按住的位置弹出，全站菜单统一为圆角浮层、按压高亮与分组的删除项；点浮岛上的上下文用量圆环，贴着圆环弹出用量面板（带自动压缩阈值刻度的环形总览、系统指令 / 历史摘要 / 对话 / 知识增强构成条与“立即压缩”）；回复生成期间屏幕始终保持常亮。生成中点运行坞的锁（宽屏在右侧检视器底栏或边缘条）进入触摸锁：全屏黑色界面只显示运行状态、当前步骤与进度，任务照常执行，返回键与其它触摸都被屏蔽，适合把手机暂时放进口袋；解锁方式在 设置 → 外观 → 触摸锁解锁方式 中选择“长按锁 1.5 秒”（默认）或“把锁拖到轨道尽头”，生成结束后锁保持到手动解锁。回复下方不再显示轮次与调用统计，生成统计从模型时间进入。AI 可以创建会话画布（可视化展示、交互小工具或临时工作台），生成中以紧凑卡紧跟在创建它的步骤下方，回合结束后在正文下方汇总为“本轮产物”（缩略图按手机宽度排版后缩小），窄窗口由顶栏选项菜单第一项“产物”（有产物时带数量）打开与文件、浏览器同样的整页列表（宽窗口在检视器“产物”页签），全屏查看可切换历史版本、复制源码，页面还能把文字写进输入框草稿供你发送；画布不能联网，页面脚本需要 Google WebView 152 及以上，否则只显示静态预览。暗色主题下没有自带暗色适配的画布页面由系统自动变暗（Android 13 起）。产物页按原型、页面、文档、图片、其它分类筛选；AI 可以做多屏可点击原型，打开后先在画板上平铺所有屏幕（可缩放拖动），再进入演示模式点着链接逐屏走；AI 交付的报告、文档、图片等文件登记为产物后保存私有快照（单文件 25 MiB、每会话 256 MiB、保留最近 5 版），本轮改动但未登记的文件出现在产物页“可能的产物”区，可收为产物或忽略。文字游戏或写作时，AI 可以建立会话状态面板（文本、数字、进度条、列表字段），每轮自动更新，运行坞的状态入口点开即可查看（数值与进度两两并排，刚更新与你改过的项带标记）并手动修改，状态随重新生成、删除消息与分支一起回退或复制。空会话中央以灯珠拼出 INFINITY 字标，光带扫过后飞散成 ∞ 形莫比乌斯灯珠环再聚回，点按切换形态、环阶段可拖动转视角，有消息后不再运行（生成动效 中可换成粒子字标、灯珠字标、粒子流环、灯珠环、字标变形或灯珠星球）；生成状态指示在整轮生成期间持续显示，默认运算矩阵，可选波浪跳跃与其余交换机指示灯风格；浮岛光效与生成状态指示按首字前、流式输出、工具执行、等待审批、重试等待五个阶段切换节奏与颜色，流式时跟随实际出字速率，等待审批时浮岛保持第三色慢闪；强调色除 10 个预设外可用色盘自定义，并可选柔和、鲜艳、忠实、表现力四种配色风格；系统关闭动画时以上效果均为静态。断网、超时或限流时自动重发本轮请求（默认 10 次，工具设置中可调 0–20），等待期间显示原因、倒计时与次数。发送后输入框与附件立即清空，生成被回滚时填回。OpenAI Chat Completions 兼容协议族按来源字段回传思考内容（满足 DeepSeek、Kimi 带工具调用时的官方要求），Anthropic 协议在工具循环内回传带签名的思考块，签名被拒时去掉思考块重发一次；Gemini API 与 Vertex AI 回传 thought signature 并支持工具调用。视觉合同和验证边界见 [design-qa.md](../../design-qa.md)。
- **会话请求头**：提供商编辑页可开启“会话请求头”（默认关闭）并填写请求头名称（默认 `x-opencode-session`，如经 NEWAPI 中转 OpenCode Go 时使用），模型编辑页可设为跟随提供商、开启或关闭，模型设置优先。开启后与某个对话绑定的请求（多轮对话、工具续请求与重试、标题、压缩与摘要、子代理、会话记忆与图谱）同时发送该请求头与 `User-Agent: Infinity-Deck/<版本>`；请求头的值是由本机随机盐与会话 ID 计算的匿名标识，同一对话稳定、不同对话（含分支与子代理）互不相同，不含密钥或对话内容。连接测试、模型目录、嵌入、重排、文档索引等不属于某个对话的请求不发送。是否发送只看设置，不按接口地址自动判断；设置随备份迁移，匿名盐不备份，重装后标识会变化。
- **会话上下文管理**：未达阈值时发送全部未摘要历史；达到阈值后先折叠较早工具结果，再将最近 N 轮之前的对话总结。会话设置可调整阈值与保留轮数，用量面板和设置均提供“立即压缩”；压缩使用当前会话模型，完整记录保留；AI 可用 `session_search` 按关键词检索原文，或用 `session_read` 翻页读取被压缩的消息。规则与兼容说明见[上下文管理](../context-management.md)。
- **会话媒体与实机诊断**：生图、MCP、下载与脚本产出的图片、视频、音频统一保存在默认落点的 `media/<日期>/`（主工作区或会话专用空间，规则见[工作区 · 自选工作区使用](workspaces.md#自选工作区使用)），模型以 `![说明](工作区路径)` 引用后在会话内显示为图片、视频、音频或文件卡片，视频与音频可内联或全屏播放，可保存到相册或下载目录、分享；支持多模态的模型可用 `view_media` 查看工作区媒体，只支持图片时视频按可调密度抽关键帧；设置页可导出有界、脱敏的 JSONL 诊断事件，辅助定位真机上的 Provider、生成和会话删除问题。
- **资料页**：内屏（宽度扣除导航轨后不少于 700dp）分两列，左列为浏览（概览、最近、待处理）、位置（存储空间、会话工作区、各工作区、Linux 主目录、已授权外部文件夹，超过 6 个折叠）、固定的文件夹（最多 6 个）与“智能体记住的”（长期记忆、对话片段、知识图谱）；顶部“问资料”输入时在右列显示本地关键词匹配，按回车（输入法搜索键）后做一次向量检索，混合文档片段、长期记忆与图谱实体，再由快速模型（默认模型设置中的“快速模型”）写出带编号引用的答案；未设快速模型只列结果，未设向量模型退回关键词匹配。结果可按类型筛选，范围为全部已索引文档或存储空间；点按文档结果打开原文并高亮命中段落，定位条在多处命中间切换。右列是页面栈，页头最左侧的展开按钮把导航轨推出屏幕、左列收成图标条，内容占满内屏；推进到第二层后，页头下方是与文件夹列表相同的路径条（如“概览 › 文档名”），点任一上级回到那一层；路径条与各页标题都只占一行，超宽时停在当前位置（标题停在开头），被裁一侧渐隐，可横向拖动查看全文；资源管理器里打开的文件预览页头只放单行标题，路径条末级为本文件，点上级回到对应文件夹。外屏为单页栈：首页顶部是问资料搜索框，下方四张统计卡兼作文件、长期记忆、知识图谱、对话片段入口，显示已索引文档、长期记忆、图谱实体与对话片段数；内屏概览的同款统计卡点按后选中左列对应项。概览“待处理”列出解析失败（附原因，可重试）、排队中（附位置）、索引中（显示准备、向量化 n / m、抽取知识图谱或保存阶段，批次重试时附原因）与“已改动待重建”（可重建）的文档，以及图谱抽取失败或待确认用量的文档（可只重试图谱或确认抽取）；每行带一枚与会话生成指示器同风格的索引指示灯（跟随所选生成指示器动画，向量化主色、抽图谱换图谱色，等待确认琥珀慢闪、失败琥珀常亮），“收集”卡把导入文件或新建笔记放进存储空间根目录。文档页阅读优先，“详情”列出索引段数、图谱实体、位置、来源与历史版本，“知识图谱”行显示抽取状态（尚未抽取、抽取中、实体与关系数、部分完成或等待确认），可单独抽取、确认或重试图谱而不重新向量化，每次手动抽取先显示用量预估；宽屏时并排显示。存储空间的列表逐行显示图谱状态：已抽取的文档行尾有图谱图标，部分抽取、待确认与图谱失败写短语，索引问题优先显示；文档单独设置了合集归属时，文件名后带合集标签（独立合集、通用知识或合集名）；文件夹行写合集类型与“已抽取 n/m”，当前文件夹的合集与进度在内屏显示为页头标题下的信息行、外屏显示为搜索按钮前的小标签（如“2/4”），点按打开合集设置；页头“更多”与文件夹行菜单提供“抽取图谱”“合集设置”，多选文档可一起抽取或“设置合集”。对话片段按会话分组，可逐段删除或清除整个会话的片段，只删记忆向量、不动会话消息。各位置统一使用同一个资源管理器：单列或双栏（列表 + 预览，不做目录树），首行“..”返回上一级，支持排序、列表/网格、隐藏文件、多选复制/移动/分享/删除、ZIP 压缩与解压（拒绝路径穿越，单文件 256 MiB、总量 1 GiB、10,000 项上限）、按名称搜索与筛选、跨位置“复制到/移动到”；删除一律永久生效，确认框写明数量与“删除后无法恢复”，应用不再提供回收站；升级后首次启动会一次性清除旧版本留下的回收内容。对话回答实际引用的文档片段与问资料答案写入引用记录：文档页“被引用”卡列出来源会话或问题，概览“最近被引用”与浏览“常被引用”按最近与次数列出被引用的文档；对话气泡“参考资料”中的文档可直接打开原文定位。删除消息一并删除其引用，撤销删除时放回。
- **资料索引后台运行**：应用可见且有文档排队或索引时，会尝试在通知栏显示当前文档及进度，并在切到后台后尽量继续处理；通知权限未授予时，索引仍可运行。侧载版在保活期间持有 CPU 唤醒锁，Play 版仅在应用可见时持有。Android 15 起同一应用的 `dataSync` 前台服务共享系统时限；服务被拒绝或超时后，索引继续由应用进程处理，后台持续运行受系统限制。
- **RAG 与知识图谱**：导入 TXT、Markdown、PDF、Word、HTML 文档，提供向量检索、FTS5、Rerank、查询重写、引用追踪、持久知识图谱聊天检索和有界图谱浏览；图谱页分全局、文档、会话三个视角，会话视角可按轮查看每轮抽出的实体，点实体查看来源文档与会话轮次。检索高级设置可调整图谱扩展、即时抽取回退及文档抽取预算；文档抽取按段落切成约 16,000 字的窗口（不重叠），默认 4 个窗口并发、每个窗口追加一轮补抽，窗口长度随图谱模型的上下文与输出上限自动收窄，模型列出的别名合并为同一实体；窗口长度、并发数与补抽轮数在 设置 → 知识库 → 知识图谱 的“抽取窗口”中调整。大文档建图需确认，超预算展示部分完成进度；模型输出达到单次上限被截断或无法解析的窗口会对半拆开重抽，图谱仍失败时保留已建好的向量与原有图谱，只把图谱记为部分完成。对话记忆按时间线注入：每条记录带所属消息的时间、按先后排列，回顾某段时间的问题（如“上周二我们聊了什么”）按时段检索；设置 → 知识库 → 知识库设置 的“每轮抽取”中可开启“提取事件与状态”（默认关闭，每轮多一次模型调用），同一“对象 · 属性”以最新值为准随检索提供。记忆与文档检索需要在 设置 → 默认模型 中选择嵌入模型；未选择时检索静默跳过，会话页只提示一次。生图、嵌入、Rerank 与查询改写都按所选模型所属的提供商发请求（地址、凭据与远端模型名取自同一提供商），所选模型或提供商被删除、禁用或缺少凭据时直接报错，不改用主提供商；Rerank 需单独选择重排模型，未选择或请求失败时保留原召回顺序。生图与 Rerank 只支持 OpenAI 兼容协议的提供商。设置 → 默认模型 → 等待响应超时 分别设置对话、图像、嵌入与重排模型多久收不到任何数据才判定超时（默认 120 / 120 / 30 / 30 秒，范围 5–1800 秒），改动后下一次请求生效；持续输出的长回复不受总时长限制。长期记忆是另一套用户级记忆：助手认为值得跨会话记住的偏好、协作反馈、项目事实与资源位置会主动写入（无需审批，会话里显示“已记住”并可撤销），所有非私密助手每轮都能看到；在 资料 → 长期记忆 中查看、编辑、删除（近 7 天新记住的标“新”），设置 → 知识库 → 长期记忆 只保留总开关。私密助手不读写长期记忆，删除会话或重新生成也不会删掉已写入的记忆。检索深度、分块、阈值等检索参数只在全局知识库设置中调整；会话只控制记忆、文档、重排序与图谱开关及检索范围，全局开关是新会话默认，智能体只保留检索范围上限与新会话默认。
- **Agent 与工具调用**：内置联网搜索、计算、隔离脚本、工作区文件（读写、补丁、新建、移动、永久删除、内容搜索；删除在任何档位都需批准，可选 10 分钟内同类免审批）、图像生成和任务规划等工具，按“命令需批准 / 免批准”两档范围授权并提供写入预览、幂等执行账本和可纠错的工具结果回传。工具设置默认 50 轮，可选 1–100 轮或“不限”；不限模式同时取消固定调用数限制，配有 token 预算、重复调用暂停、上下文压缩和私有大输出分页读取。首次“不限＋免批准”执行需确认，聊天页与前台通知显示进度且可停止；预算耗尽后自动总结。技能分三级：随应用内置的只读技能 `infinity-deck`（应用运行环境、权限、技能管理与规则修改指南，在设置与会话面板中单独列为“内置技能”一组，不可停用或编辑），用户级位于 `/skills`、所有会话共享，目录型工作区的 `.agents/skills/` 为项目级技能（需用户信任）；Agent 用文件工具查看、新建、修改技能或 clone 技能仓库，写入技能目录逐次审批（可在审批卡上选 10 分钟内同类免审批），不另需书面同意。系统提示固定段说明当前模式、权限档、工作区、Linux 可用性与技能目录，并区分长期记忆与智能体/会话提示词。模型在任务匹配或用户以 `$技能名` 点名时按需加载技能指令、参考文件并运行附带脚本；用户级技能随备份迁移。设置 → 技能包 顶部的“商店”从官方目录或自行添加的 https 目录浏览、搜索与安装技能，按“全部 / 已安装 / 可更新”与分类筛选；详情页列出来源、版本、许可、大小、SHA-256 与完整文件清单，下载后核对大小、哈希、文件清单与技能名称再安装。官方技能安装后启用，第三方技能安装后停用；“含脚本”“仅侧载”逐项标注，仅侧载技能在 Play 版仍可安装并提示能力受限。本地改过或同名冲突时先确认再覆盖；应用启动时每天最多自动检查一次更新，可更新数量显示在商店入口。任务计划以融入输入框顶部的单行计划条呈现（当前步骤、进度与进度线），点击向上展开步骤列表与“标记已完成 / 继续处理”，出现、收起与展开均带尺寸动画；计划全部完成后停留片刻自动收起；× 隐藏未完成计划（收为状态胶囊，计划推进后自动重新出现）或清除已完成计划。生成停止后仍可人工继续或销项，不会把残留计划误报为仍在生成。
- **智能体头像**：头像有符号、生成与照片三种样式。符号取自 390 个 Material Symbols Rounded，按分类浏览或用中英文搜索；生成头像是按智能体 ID 决定的渐变首字母，可换一批；照片沿用裁剪流程。12 种色调自动适配浅色与深色主题。智能体编辑页点主图或“头像”行打开选择器，按“完成”保存。新建智能体默认使用生成头像；仍为出厂样式的预置智能体升级后自动换成新头像。
- **智能体管理工具**：主会话提供 `agents_read` 与 `agents_write`，子代理与分支会话不提供。`agents_read` 免审批，`target` 为 `agents`（全部智能体的名称、描述、默认模型与会话数）、`agent`（单个智能体的可写字段与提示词全文，另附权限档、默认工作区、MCP 的显示名）、`sessions`（某智能体的会话列表）或 `session`（单个会话的标题、会话提示词、模型、推理参数、启用的技能与 MCP），只返回配置，不返回消息。`agents_write` 的 `op` 为 `create_agent`、`update_agent`、`create_session`、`update_session`，`fields` 只接受白名单字段：智能体为名称、描述、提示词、模型、采样参数、推理强度、MCP、默认工作区与默认开启工具；会话为标题、会话提示词、模型、推理参数、启用的技能与 MCP（新建会话另可指定归属智能体）。权限档、运行模式、工作区绑定、头像与删除在审批前直接拒绝，并指向界面入口；模型、技能、MCP 与工作区引用不存在时同样不进入审批。每次写入都需逐次批准（风险标签“修改智能体”，菜单只有“仅批准这一次”），审批卡列出申请原因、有变化的字段、提示词差异与影响范围；执行时若目标字段已被他人改动则失败，要求重新读取后再提交。修改从各会话的下一轮生效，本轮剩余的工具循环不变；新建智能体的权限档固定为“命令需批准”，新建会话不发起对话。
- **提示词历史版本与编辑页冲突处理**：智能体提示词每次变更记入历史（工具修改记“智能体”、编辑页保存记“我”、恢复记“恢复”），首次变更前的内容作为基线，与上一版相同时不重复记录，保留最近 20 版。编辑页提示词下方的“历史版本”可对比任一版与当前内容并恢复。编辑页按字段保存：页面加载后智能体改过而你没动的字段静默刷新并短暂高亮；两边都改了同一字段时显示提示条，可“采用新内容”或“保留我的”；提示词编辑器打开期间被改动时，编辑器顶部提示条可查看差异，放弃的一份存为历史版本。会话提示词不做历史版本，审批卡差异即记录。
- **智能体知识检索**：智能体编辑页的“检索方式”决定检索如何发生：每轮自动（发送前检索并注入）、仅工具（模型按需调用 `knowledge_search`，每轮最多 6 次）或两者；会话关闭工具或模型不支持工具调用时回到每轮自动。“知识库文件访问”为关闭、按需申请或始终：按需申请时模型调用 `request_knowledge_access`，会话出现访问授权审批卡，批准后知识库以只读方式挂载到 `/mnt/<别名>`，只能用文件工具读取，命令不可达；“始终”在新会话首次创建且工具开启时直接挂载，移除后不会被补回。外部文件夹面板也可手动“挂载知识库”。检索详情为每条结果标注引用编号、相似度与重排分，以及可读取的路径。
- **联网搜索提供商**：设置 → 工具 → 联网搜索中可选择 DuckDuckGo、Keenable、Tavily 或 SearXNG；模型只看到一个 `web_search` 工具（参数只有 query），工具调用与会话联网检索共用该选择。Keenable 无需密钥即可使用公共共享额度，可选 API Key 使用账户额度；密钥由安全存储管理，仅在用户选择包含密钥的加密备份中导出。搜索结果保留网页来源、链接与摘要。
- **多会话并发与提问卡**：最多 16 个会话同时生成，其余按发送先后排队，会话列表标出生成中、排队中、待批准与待回答；停止或删除只影响该会话，多个会话后台生成时合并为一条前台通知。本地模型的所有调用共用一把推理锁。AI 需要你做决定时可用 `ask_user` 一次提出若干单选、多选或自由回答的问题，会话中以提问卡呈现（单选自动下一题，可跳过，也可在输入栏写其他回答）；等待回答时本轮暂停、释放并发名额并在后台通知，回答后在原轮次继续，已答内容保留为“你的回答”摘要。子代理不能提问。需要密码、令牌或 API Key 时，AI 改用保密输入卡（`request_secret`），值直接写入 Git、SSH、服务商凭据、后台任务终端或本会话环境变量，不进入对话；命令产生的保密值经 `capture_secret` 存入本会话保密库，再由保密输出卡（`show_secret`）在设备验证后交给你查看、复制、另存或销毁。输入栏发送前会提醒疑似令牌或私钥。
- **后台子代理**：AI 用 `agent_task` 派出的子代理默认在后台运行，本轮立即拿到子代理 ID 继续工作，子代理完成后结论自动交回：会话空闲时发起新一轮，生成中在当前步骤后插入，等你回答或批准时暂缓；同一结论只交回一次，应用重启后补送。一次最多派出 8 个，全应用最多 32 个子代理同时运行，其余排队，与会话的 16 个生成名额互不占用。AI 也可以等待结果（`background=false` 或 `agent_wait`），等待时卡片显示剩余时间与“转入后台”，点一下主会话立即带着当前进度继续。子代理请求遇到限流、断网或超时时按主会话相同规则自动重发同一轮，过程中显示原因与次数。AI 可以用 `session_read` 查看进度（也可翻看子代理完整历史）、`session_send` 追加指令或要求收尾（`wrapUp` 后最多再走两步给出结论）、`session_stop` 停止；你也可以在卡片或查看页停止单个子代理。子代理默认跟随会话模型；智能体设置的“子代理”一节可固定另一个模型，或允许智能体从勾选的模型中按任务指定，指定模型不可用时直接报错、不改用其它模型。子代理沿用主会话的执行模式（免批准档下同样不审批，强制审批的操作除外），AI 可以按任务限定可用工具。查看页列出任务、工具档位、模型、轮数上限、用量与过程，主会话的追加指令、转入后台与停止也记在过程里；结论过长时全文写入工作区 `subagent-results/`，结论里给出路径。子代理用量计入用量统计的“子代理”分类。
- **分支会话**：AI 判断某项工作适合独立进行时，用 `session_branch` 提交工作方案，会话底部出现方案卡：目标、步骤与三项可轻点切换的选择（工作方式：共用主会话工作区或新建 git worktree；上下文：全新或继承主会话摘要与最近消息；审批模式：默认沿用主会话）。你可以“派发到分支”、“在此执行”（主会话按同一方案自己做）或“不需要”。分支是独立的普通会话，与其它会话共用 16 个生成名额，在首页排在主会话下方并带分支标记，会话开头的方案入口与顶栏分支图标可回到主会话。主会话、分支与子代理之间用 `session_send` 互发消息，收到的消息显示来源并可一键打开对方；空闲时收到消息会自动开始新一轮，连续 8 次无你参与的自动处理后暂停，等你回来继续。`session_list` 列出同一家族的会话；读取同助手的其它会话需要你逐次批准。Git 页“分支”页签列出仓库全部 worktree 与在用的会话；删除绑定了 worktree 的分支时可勾选一并移除（不强制，有未提交改动时 Git 会拒绝并保留）。
- **Agent 浏览器**：Agent 用 `browser_open`、`browser_snapshot`、`browser_click`、`browser_type` 在应用内的系统 WebView 中打开网页、读取可操作元素（带 `e12` 这类编号）与正文、点击和填写文本框，适合需要交互或登录才能看到内容的网站。浏览器使用独立配置文件，Cookie 与登录状态和其它应用隔离、跨会话保留；目标地址与 `web_fetch` 共用网络访问判定。手机会话的“浏览器”在顶栏选项菜单首组（Agent 使用中或需要你处理时菜单按钮挂状态点），宽屏改为检视器侧栏常驻的“浏览器”页签（侧栏收起时边缘条显示状态点），可随时旁观；地址栏可直接输入网址或搜索词（不是网址时用 Google 搜索，缺协议的域名补 https，只打开 http/https），Agent 还没打开网页时也能自己先打开，旁边是后退、前进与刷新；“接手”、自己点导航或从地址栏前往后 Agent 暂停，“交回 Agent”后继续。密码、支付卡与验证码字段只能由你填写：Agent 遇到时浏览器标出该字段并提示“需要你登录”，你填好点“完成，交回 Agent”，Agent 看不到填写内容。四个工具在 设置 → 工具设置 → 内置工具 的“联网”分组中开关。需要支持多配置文件的 WebView，版本过低时提示更新。
- **SSH 与远端终端**：设置 → 工具 → SSH 主机与终端中管理主机别名、密码或密钥认证，支持生成 Ed25519、导入口令保护的 OpenSSH 私钥和复制公钥。首次连接需要确认 SHA256 指纹，指纹变化会拦截；Agent 可通过别名执行命令、读写 SFTP 和使用常驻 PTY，“命令需批准”档下每条命令逐次审批，并支持大输出分页。用户终端支持 ANSI、滚动历史、控制键与旋转调整窗口，本地转发仅监听 `127.0.0.1`。用户终端一直保持连接，直到手动断开、从最近任务划掉应用或应用退出，可选“空闲自动断开”；添加主机时可从内置 Tailscale 的 tailnet 设备中选择。“允许 Agent 管理 SSH 主机”（默认开启，可在同一页关闭，不随备份迁移）开启时，Agent 可列出、新增、修改、删除主机，并为密码主机安装本机生成的 Ed25519 公钥实现免密登录；这些变更在两档权限范围下都逐次审批，密码与指纹只在应用弹窗中由用户输入和确认，工具结果不含凭据。
- **Termux 本机终端**：两个发行渠道均可从设置 → 工具 → Termux 接入与诊断启用集成。`termux_exec` 在 Termux 的 bash 中后台执行，支持工作目录、stdin 和 1–600 秒超时，默认 60 秒；沿用 PROCESS 审批，目标绑定 `termux` 与完整命令。诊断页提供安装、外部调用开关、系统权限、SSH 公钥复制和主目录 SAF 挂载引导。
- **内置命令执行**（内置模式会话）：无需 Termux，`shell_exec` 用系统 `/system/bin/sh`（POSIX sh 与系统 toybox，命令随设备不同）、`python_exec` 用随 APK 打包的 Python 3.14（仅 arm64-v8a，标准库完整，附带 dulwich）直接在会话工作区根目录运行；shell 中可用 `python3`/`python`，以及基于 dulwich 的 `git`（clone、commit、log、diff、push、pull 等常用子命令，远端只支持 HTTPS，不支持的子命令返回 `GIT_UNSUPPORTED`）；侧载版另有 `pip`，可把纯 Python 包装到应用用户目录（含原生扩展的包无法导入），Play 版不提供 pip。`.git` 内部文件入索引但不进入资料向量化。“命令需批准”档逐条审批，“免批准”档不审批；审批卡以“内置命令”类别条写明命令以 Infinity Deck 身份运行、可访问全部应用数据、不受工作区限制，删除或覆盖的文件无法恢复。命令结束后检测数据库、`shared_prefs`、`no_backup`、用户级技能目录与诊断日志的变化，在工具行下方常驻标出；系统提示词要求模型改动这些关键数据前取得你的书面同意（用户级技能目录除外：改用文件工具，由审批卡确认）。运行期间独占工作区写锁（文件工具的读写排队等待），结束后按磁盘对账索引并在 `workspace_changes` 中列出新增、修改、删除与移动；保留路径、符号链接与特殊文件不入索引并给出警告。默认 60 秒、最多 600 秒，超时、取消或命令结束时结束整个进程组，stdout/stderr 各保留尾部 32,000 字符。运行期间持有唤醒锁，侧载版在通知栏显示命令并可停止（Play 版只有唤醒锁）；系统冻结的时间不计入超时，ColorOS 等系统需把 Infinity Deck 设为“完全允许后台行为”，离开应用后命令才能持续运行。
- **内置 Linux 环境（侧载版）**：设置 → 工具 → 本机与远端 → Linux 环境，一键安装随 APK 打包的 Alpine Linux（proot，仅 arm64-v8a，无需 Termux 或 root）。开启“命令在 Linux 中运行”后，`shell_exec` 与 shell 后台任务在 Alpine 中执行，可用 `apk add` 安装软件包；另有本地终端、Linux 文件浏览、软件包与镜像源管理、命令完整输出查看，`/root`、`/home`、`/opt`、`/srv` 及其子目录可在工作区选择器中逐级浏览并选为会话工作区（系统目录与运行时绑定点不可选），`/root` 同时出现在系统“文件”应用中。交互式命令（如需要逐步确认的安装脚本）运行在伪终端中，终端会答复光标位置与颜色查询，提问可用 `job_input` 逐步作答。使用方式与边界见[执行环境 · 内置 Linux 环境](execution-environments.md#内置-linux-环境)。
- **内置 Tailscale**：设置 → 工具 → Tailscale 启用后，Infinity Deck 在进程内运行一个 Tailscale 节点（tsnet），不占用系统 VPN，可与其它 VPN 同时使用；支持浏览器登录或 auth key、自建控制服务器（Headscale）与临时节点；tailnet 内哪些设备可以访问由 tailnet ACL 决定，应用不另设设备白名单。SSH 主机、`shell_exec`、`python_exec`（含内置 git）、应用内 HTTPS 请求以及模型提供商（对话、向量化、重排、生图）可直接访问 tailnet IP 与 MagicDNS 名称，其它目标保持原有路径；`web_fetch`、`media_fetch` 与脚本联网访问 tailnet 时固定经内置 Tailscale 代理，未连接时直接失败；Agent 可用只读工具 `tailnet_status` 查看节点与设备，以及每台设备的连接路径。设备列表为每台在线设备标出连接路径：局域网或公网直连、设备中继、经哪个 DERP 区域中转，或尚未建立连接。点开一台设备可以按需 Ping，查看逐次的路径与延迟；界面与工具结果都只给局域网或公网的分类，不显示对端的真实地址和端口。提供商表单按接口地址自动识别“公网 / Tailscale 内网”API 源，并可从 tailnet 设备下拉框选择网关设备，填入该设备 MagicDNS 全名的 https 地址（可在网关设备上用 `tailscale serve` 提供），也可以手动填写 http 地址；发送到内网模型时会等待内置 Tailscale 接入后自动继续，未接入时请求直接失败而不回退直连（内置 Tailscale 关闭时立即提示去开启），模型选择器以公网与 Tailscale 两盏指示灯显示连通状态。节点只在 Infinity Deck 运行期间在线，退出后下线。
- **MCP 服务器**：工具的 MCP 配置可添加 HTTP 或 HTTPS 服务器，公网、局域网、tailnet 与本机地址均可，离开本机且不经 tailnet 的 http 地址在输入框显示“未加密”提示。Bearer 访问令牌可选，由 SecretStore 加密保存在本机，发现和执行均携带；本机回环 HTTP（`127.0.0.1`、`localhost`、`::1`）上的工具按 PROCESS 风险审批，同机其它应用也可能访问该端口，建议配置 Bearer 令牌。
- **会话工作区**：资源管理器与资料页同样按目录下钻浏览（页头只有一个返回按钮，子目录内回到上一级；上级路径可点击跳级，系统返回同样逐级退回），搜索结果平铺并显示所在路径，点击即进入所在目录。按 Session 隔离文件根目录，覆盖导入、原子写入、版本和路径逃逸防护；文档索引使用版本化目标与失败重试，进程重启后按当前文件版本和 KG 配置补建缺失任务。
- **后台任务**：`shell_exec`、`python_exec`、`termux_exec` 传 `background: true` 即在后台运行并立即返回任务号，默认最长 2 小时（上限 24 小时），结束后可通知或自动唤醒会话发起下一轮；`job_status`、`job_wait`、`job_stop`、`job_list` 查询、等待和停止。内置模式的会话专用空间任务在副本里运行、结束后先合入再通知，冲突保留前台版本并把后台版本放进 `background-conflicts/`；Linux 任务直接使用原目录。会话私有目录索引在任务结束通知后由后台合并对账，查询状态与日志不触发全量扫描；有效持久身份基线支持 Linux 命令内同卷移动保留 UUID 和版本关联，首次或基线失效时按路径对账。侧载版退出应用后继续运行；Play 版只在应用位于前台时保证运行。聊天页活动标签与面板显示实时输出、停止按钮与日志入口。Linux 会话里的脚本可运行 `infinity-wake [--key K] [--title T] [消息]` 唤醒智能体，会话空闲时发起一轮回复（同一会话 60 秒内最多一次，期间消息按 key 合并）。
- **定时任务**：AI 可在会话中创建单次、间隔或 cron 定时任务（创建总需你批准，审批卡列出接下来三次触发时间），适合 Agent 在长任务中挂轮询（如定期检查构建状态、完成后自行取消）；应用在前台时由应用内计时器准点触发，退到后台时由系统闹钟或 JobScheduler 兜底（可能被系统推迟）。到点在会话里插入“定时”触发行并发起一轮回复，沿用会话的权限范围；需要你处理时暂停并通知，点通知回到会话继续。前台固定间隔最短 1 分钟，重复任务退到后台后精确闹钟间隔至少 5 分钟、系统择时至少 15 分钟；单次提醒用 1–10080 分钟倒计时，你给出具体钟点时才用绝对时间。每会话最多启用 5 个、共 20 个。设置 → 工具 → 后台与定时汇总全部任务和运行条件（精确闹钟、电池优化、通知）。定时任务只存在本机，不进入备份。
- **画布文件**：画布当前版本同时保存为会话工作区的 `canvas/<标题>.html`，可在资源管理器或用文件工具、命令编辑，修改在下次打开或读取画布时成为新版本。
- **工作区三分类**：会话专用空间、内置文件系统与（侧载版）设备文件系统；Agent 可设默认工作区，会话可单独切换，文件工具、`shell_exec`、`python_exec` 与内置 git 直接在该目录工作，资源管理器可复制、移动、重命名、删除与恢复文件，删除会话时可把专用空间文件保留到内置文件系统；会话资源面板为 git 仓库提供只读的变更与提交差异面板，文件工具执行卡与审批卡显示逐文件增删行数与差异。
- **外部文件夹挂载**：文件面板可为当前会话添加 SAF 文件夹或（侧载版）存储路径，以 `/mnt/<别名>/...` 供现有文件工具读写；挂载只属于添加它的会话且一律可读写，支持浏览预览、加入资料快照和恢复删除副本。存储路径挂载另可被命令以真实路径访问，SAF 授权的文件夹只对文件工具可见；系统提示词逐个列出两者。侧载版另提供经过系统“所有文件访问”授权的共享存储真实路径入口，Play 版仅提供 SAF。
- **长文档安全编辑**：严格大于 1 MiB 的文件仅加载元数据；已读取正文严格超过 32K 个 UTF-16 代码单元、2,000 行或单行 16K 个 UTF-16 代码单元时自动进入性能保护，只预览约前 16K 字符，但复制和保存始终使用完整全文。一次输入跨过软线时，已修改内容不会被截断，仍可完整完成 CAS 安全保存。
- **安全备份与恢复**：在 设置 → 备份 中手动备份到本地文件或 WebDAV，应用不会自动备份或恢复。备份按层选择：**核心**始终包含（设置与提供商配置、智能体及其提示词历史、长期记忆、参数方案、MCP 服务器、自定义工具、工作区登记、被引用的头像、用户级技能目录）；**资料**（知识库文档、标签与知识库系统会话）和**会话**（会话、消息、附件、产物、上下文摘要、任务节点）默认选中；**工作区文件**（会话专用空间里的文件）默认不选，目录工作区建议用 Git 同步，不在备份里；**密钥**（提供商 API Key 等）默认不选，选中时必须加密并设置密码。备份页显示每层与合计的估算大小；导出完成后列出每层大小和“未备份”清单（文件缺失、内容变化或无法读取；头像文件不存在或不在头像目录中时清除该引用并列为跳过项）。导出、上传、下载与导入全程流式写入应用私有缓存，未压缩内容合计上限 512 MiB、单项 128 MiB、内容条目与技能目录合计 10,000 项，导出前按估算检查私有缓存剩余空间；技能目录中的应用内部目录（`.infinity` 开头）不进入备份，技能的 `.git` 在剩余预算内随包，放不下时跳过并记录仓库地址、分支与提交号。备份失败时分别说明可自行处理的原因（超过容量上限或存储空间不足、会话文件被删除或在应用外被修改、技能目录含无法备份的内容），其它失败只显示通用提示，原因写入可导出的诊断日志。恢复时只替换包里有的层，包里没有的层保留本机现有数据；恢复完成后列出替换的层和需要处理的事项（例如会话的工作区文件不在包里、显示为不可用，以及技能 `.git` 未随包、需要重新 clone 的仓库）。旧版应用导出的格式 1、2 备份包及不含分层清单的格式 3 备份包仍可导入，上限为 16 MiB。首次引导的第一个配置步骤也提供“从备份恢复”，可选本机 .iwb 文件或 WebDAV 备份，确认前显示备份时间、包含的层、是否加密与来源版本；恢复提交后直接进入应用并保留引导中选的语言，失败时回到引导页、数据保持原样；备份不含密钥时，恢复结果弹窗提供“去填写”跳转到提供商管理。
- **本机头像管理**：个人头像与 Agent 自定义头像共用系统图片选择和应用内头像编辑器：圆内清晰、圆外压暗，拖动时在圆内显示三分网格；可拖动、双指缩放（铺满到 5 倍，图片始终铺满圆形）、双击切换、旋转 90°、水平镜像、重置或换一张，并实时预览资料页、列表与对话三种尺寸，按“完成”输出 512×512 方图；连续替换图片使用新的内容身份，避免图片缓存继续显示旧头像。Agent 自定义图片与内置向量头像都会提交本地数据库，Agent 首页复用同一持久化头像选择展示。
- **后台持续生成**：前台发起的当前生成任务在切后台、锁屏、旋转或 Activity 重建后继续，通过前台服务通知返回会话或停止任务。回到对话首页时，正在生成的会话在列表中以生成状态指示替换时间（样式随外观设置），会话标题固定单行、过长时跑马灯滚动，等待批准的显示“待批准”；离开再回到会话，思考计时接着走，输入框草稿以离开时为准。
- **本地优先**：会话、文档和配置保存在设备本地；云端模型调用直接连接用户配置的服务商。
- **会话宠物**：设置首页“通用”分组的“宠物”默认关闭。导入 `.idpet` 宠物包后，宠物站在会话页输入浮岛上方，随生成、调用工具、等待审批、完成与出错切换姿势、表情和台词，空闲时走动、坐下、张望；可点按互动，长按提起拖动，松手落回浮岛。宠物包可设为默认、导出、删除，或关联到模型。台词可由单独指定的台词模型生成（无工具短请求，用量计入“宠物台词”），未指定时用宠物包自带台词。走动与过渡 30 帧每秒，站定 15 帧，逐帧片段按片段帧率（4–30），省电或“移除动画”时站定后每秒 2 次。松手按速度落回、抛出反弹或甩出收起，摇晃手机、宠物页或 Agent 的 `pet` 工具可唤回；提起时屏幕上部出现云朵或泡泡栖息点，可落座、点破泡泡、吹散云朵（吹气默认关闭，开启时申请麦克风权限，只读取音量）。宠物包结构见内置技能“宠物包制作”。

## 后台生成边界

后台生成覆盖用户在前台主动发起的单个当前任务：

- 支持切后台、锁屏、旋转和 Activity 重建；
- 通知可返回准确会话或停止生成；
- 通知权限被拒绝时可退化为仅前台生成；
- 不支持设备重启后续传；同时生成的会话数上限见“多会话并发与提问卡”；定时任务与后台任务唤醒触发的轮次在应用级全局串行排队，见“定时任务”。

## 录音听写

长按录音列表的一行进入多选。搜索后，「全选结果」只操作当前匹配的录音，栏头会提示已选但不在当前结果内的数量。确认删除后，本机音频、逐字稿和整理稿会移除，已保存到资料库的文档会保留。正在录制或有待恢复操作的录音不可选。

资料首页页头的「＋ 添加」提供录音、导入文件和新建笔记。导入的文件和新建的笔记保存到存储空间根目录，支持索引的格式可在「问资料」里搜索正文。填写笔记名称时可以省略 `.md`，应用会在保存时补上 Markdown 扩展名。

在「＋ 添加」中选择「录音」进入可搜索的录音记录，点击「开始录音」才使用麦克风。点列表中的录音可打开详情，标题栏返回和系统返回都先回到录音记录，保留列表位置。详情的「继续录音」将新音频和逐字稿追加到原记录，并保留手工整理稿。录制时可放弃。新录音整条清除，续录恢复到开始追加前。设置 → 知识库 → 录音整理提供快捷设置磁贴和桌面快捷方式。外部应用可调用 `ACTION_VIEW` 打开 `infinitydeck://recording/open`，或用 `com.promenar.infinity.action.OPEN_RECORDING` 打开录音页，用户点击开始后才申请麦克风。磁贴在锁屏时先请求解锁。

实时转写使用应用内下载的 [X-ASR 480ms 中英标点流式 Zipformer2](https://github.com/Gilgamesh-J/X-ASR)（Apache-2.0，由 [sherpa-onnx asr-models 发布页](https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models)分发），输出自带标点和大小写。在「录音整理」或逐字稿栏下载模型，约 134 MB，安装后约 169 MB。模型未装时照常保存音频，安装后可点「重新识别」生成逐字稿。录音支持暂停、续录、后台前台服务、系统中断后的恢复和按段时间戳回听。结束后在资料库存储空间根目录生成 Markdown，可从文档页的麦克风按钮打开原音。原始音频保存在应用私有目录，每小时约 115 MB，单次上限约 17 小时；原音和设备上的整理授权不随应用备份迁移。资料库 Markdown 可按资料层备份，自动向量化与图谱抽取跳过这类文档。已结束或中断的录音可在录音页顶栏删除：音频、逐字稿和整理稿从本机移除，已保存到资料库的 Markdown 保留。反过来，在文件管理或资料库里删除录音生成的 Markdown（或包含它的文件夹）时，对应录音一并删除；正在录的那一条保留，结束后重新保存到资料库。

整理默认使用设置中的快速模型。快速模型未就绪且允许回退时，使用已加载的本地主生成器。可单独选仅本地或仅转写。Qwen3-0.6B Q8_0 是侧载版推荐本地模型。云端整理按每段录音和具体模型路线确认。录制中的草稿逐批校对已定稿片段并保留原语言。开始新录音时，本地整理可在首段听写定稿后立即开始，后续批次在停顿时处理。录音结束后先保存音频和逐字稿，再根据目标语言生成摘要及发言人观点；可按时间戳回听。输出语言可在录音设置中设为默认值，每条录音也可单独更改。日文等输出语言需要整理模型支持，逐字稿保留听写语言。点录音标题改名，在整理稿栏直接编辑。重生成成功后才替换已保存的整理稿。

首次启动可跳过「离线录音准备」，也可选装中英听写、说话人区分模型和侧载版推荐本地整理模型。设置中的「离线录音准备」可继续下载。

在「录音整理 → 热词库」管理常用人名和术语，可填写写法与可选读法，例如 `llama.cpp=Lama CPP`。批量导入每行一条，支持半角和全角等号。录音操作菜单可增加本录音热词、关闭该录音对全局热词库的使用。热词用于识别时的加权和读法替换，也为整理提供术语。逐字稿为当前有效热词加下划线。现有录音可用当前热词重新识别。手动编辑过的整理稿可选择只更新逐字稿，或重新识别并整理。

开启「区分说话人」后，录音结束时在本机分析并标注说话人。内屏并排展示逐字稿和整理稿，外屏通过页签切换。点说话人标签可修改单段归属、新建、改名、指定声纹库人员或合并。整理会按说话人分段；已手动编辑的整理稿保留到用户选择重新整理。

声纹库支持录入 15 秒样本，也可从现有录音保存或补充样本。声纹数据保存在本机，并随启用密码加密的应用备份迁移。云端整理请求可包含说话人名称、逐字稿与校对上下文。说话人分段、声纹匹配和音频处理均在本机完成。

## GGUF 本地推理

签名侧载版支持 llama.cpp CPU 推理。到「设置 → 本地模型」，在「模型库」下载录音整理模型或导入 GGUF。开启「本地推理」后，在「模型分配 → 主生成器」选择模型并加载。模型菜单提供详情、固定和删除。固定用于录音整理时记录 SHA-256，启动加载前复核摘要。切换模型前先解除固定，卸载时模型文件保留在库中。Play Release 提供离线听写、云端整理和仅转写。
